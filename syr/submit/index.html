ܡܘܣܦ
ܒܝܬܐ ܪܫܝܡܐ ܠܫܢܐ ܐܬܘܪܝܐ ܥܠ ܡܕܪܫܬܐ ܠܫܢܐ ܣܘܪܝܝܐ ܫܘܐܠ̈ܐ ܡܘܣܦ

ܐܝܟܢ ܡܘܣܦ ܡܕܪܫܬܐ، ܕܘܪܐ ܝܢ ܡܠܦܢܐ

ܠܝܬ ܚܫܒܢ̈ܐ ܘܠܐ ܦܘܪ̈ܡܐ ܒܕܘܟܬܐ. ܡܕܪ̈ܫܝܬܐ، ܕܘܪ̈ܐ ܘܡܠܦܢ̈ܐ ܟܬܒܝ ܠܢ ܐܓܪܬܐ، ܘܚܢܢ ܡܘܣܦܝ ܠܪܫܝܡܐ ܡܓܢ.

ܬܠܬ ܕܪ̈ܓܐ

  1. ܢܣܘܟ ܠܛܘܦܣܐ ܠܬܚܬ ܝܢ ܕܘܫ «ܟܬܘܒ ܐܓܪܬܐ».
  2. ܡܠܝ ܡܕܥܢܘܬܐ ܥܠ ܡܕܪܫܬܘܟ، ܕܘܪܘܟ ܝܢ ܝܘܠܦܢܘܟ.
  3. ܫܕܪ ܐܓܪܬܐ ܠܢܝܫܢܢ. ܒܚܪܝ ܚܢܢ ܟܠ ܒܥܘܬܐ ܘܦܢܝ ܒܝܘܡ̈ܢܐ ܩܠܝܠ̈ܐ.

ܐܢ ܠܐ ܦܬܚ ܒܪܢܡܓܐ ܕܒܝܠܕܪܐ، ܢܣܘܟ ܠܛܘܦܣܐ ܘܫܕܪ ܡܢ ܐܝܢܐ ܒܝܠܕܪܐ ܕܒܥܝܬ.

ܪܝܫܐ Listing request / ܒܥܘܬܐ ܕܪܫܝܡܐ

ܫܡܐ: 
ܙܢܐ (ܡܕܪܫܬܐ / ܕܘܪܐ ܕܠܫܢܐ / ܡܠܦܢܐ): 
ܠܫܢܐ (ܣܘܪܝܬ (ܐܬܘܪܝܐ ܚܕܬܐ) / ܛܘܪܝܐ (ܣܘܪܝܬ) / ܣܘܪܝܬ ܘܛܘܪܝܐ): 
ܡܬܐ, ܡܕܝܢܬܐ: 
ܢܝܫܢܐ: 
ܐܣܟܝܡܐ (ܦܐܬܐ ܠܦܐܬܐ / ܒܐܢܛܪܢܝܬ / ܦܐܬܐ ܠܦܐܬܐ ܘܒܐܢܛܪܢܝܬ): 
ܠܫܢ̈ܐ ܕܝܘܠܦܢܐ: 
ܒܝܠܕܪܐ ܐܠܩܛܪܘܢܝܐ: 
ܬܠܝܦܘܢ: 
ܕܘܟܬܐ ܐܠܩܛܪܘܢܝܬܐ: 
ܡܦܫܩܢܘܬܐ: 

ܡܫܪܪܢ ܕܐܝܬ ܠܝ ܙܕܩܐ ܕܦܪܣܡܢ ܐܗܐ ܡܕܥܢܘܬܐ ܘܡܩܒܠܢ ܠܐܘܪܚܐ ܕܛܘܫܝܘܬܐ.

ܠܡܬܩܢܐ ܝܢ ܠܡܫܩܠܐ ܪܫܝܡܐ، ܟܬܘܒ ܠܗܢܐ ܢܝܫܢܐ ܘܗܒ ܐܣܘܪܐ ܕܝܠܗ. ܛܘܫܝܘܬܐ
